# Personal Portfolio Website

A responsive and interactive personal portfolio website built to showcase my projects, technical skills, internship experience, certifications, education, and resume.

🔗 **Live Portfolio:** https://aryan-personal-portfolio.vercel.app

---

## 🚀 Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
- **Interactive UI:** Smooth animations, hover effects, scroll reveal animations, and theme switching.
- **Dynamic Content:** Projects, experience, certificates, skills, and education are rendered dynamically using JavaScript.
- **Project Showcase:** Displays featured projects with technologies used and links to GitHub repositories and live demos.
- **Project Image Modals:** View project screenshots through interactive image previews without leaving the page.
- **Certificate Section:** Showcases professional certifications and internship credentials.
- **Resume Access:** Provides direct access to my latest resume.
- **Contact Section:** Includes direct links to GitHub, LinkedIn, and email.
- **Back-to-Top Navigation:** Smooth scrolling navigation for improved user experience.

---

## 🛠️ Built With

- **HTML5** – Semantic structure and content.
- **CSS3** – Responsive layouts, custom properties, Flexbox, Grid, animations, and theme styling.
- **Vanilla JavaScript (ES6)** – Dynamic content rendering, theme switching, modal functionality, and interactive features.
